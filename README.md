# Data Visualization Tool

## Project Overview
A Python application for analyzing datasets and generating visual representations of data. It includes a graphical user interface (GUI) for interacting with the dataset and exploring visualizations.

## Technologies Used
- Python
- Pandas for data handling and analysis
- Matplotlib for charts and graphs
- Tkinter for the graphical user interface
- CSV for dataset storage

## Features
- Load and explore CSV datasets
- Generate bar charts, line charts, and pie charts
- View basic statistical summaries
- Search dataset records
- Add, update, and delete records through the GUI

## Project Structure
- `data.csv` — sample dataset
- `data_visualization.py` — command-line application
- `data_visualization_gui.py` — graphical user interface

## Setup Instructions

### Prerequisites
Install Python 3.x.

### Install Dependencies
Open a terminal in the project folder and run:

```bash
pip install pandas matplotlib
```

### Run the Application
To launch the graphical interface:

```bash
python data_visualization_gui.py
```

To run the command-line version:

```bash
python data_visualization.py
```
